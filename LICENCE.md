## ⚙️ Configuration

Settings are stored in `config.json` at `%APPDATA%\GenshinTrainer\config.json`.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Insert"` | Key to toggle menu |
| `process_name` | String | `"GenshinImpact.exe"` | Target process |
| `esp_enabled` | Boolean | `true` | Enable ESP |
| `safe_mode` | Boolean | `true` | Restricts risky features |
